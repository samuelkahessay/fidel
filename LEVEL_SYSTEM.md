# Learn Amharic - Level System & Topic Classification

## Overview

This document outlines a CEFR-aligned level progression system and topic-based curriculum for the Learn Amharic app.

---

## Level System (CEFR-Aligned)

### Level 1: Beginner (A1) - "Selam" 
**Goal:** Basic survival Amharic - introduce yourself, simple phrases

| Metric | Target |
|--------|--------|
| Vocabulary | 200-300 words |
| Study Time | ~30 hours |
| XP Range | 0-500 |
| Fidel Mastery | 50% (basics) |

**Can-Do Statements:**
- Introduce yourself (name, origin)
- Greet people appropriately
- Count 1-20
- Order basic food/drinks
- Ask simple yes/no questions

### Level 2: Elementary (A2) - "Wendim" (Friend)
**Goal:** Handle common daily situations

| Metric | Target |
|--------|--------|
| Vocabulary | 500-800 words |
| Study Time | ~60 hours |
| XP Range | 500-1500 |
| Fidel Mastery | 80% |

**Can-Do Statements:**
- Describe your daily routine
- Talk about family members
- Give and follow directions
- Make simple purchases
- Express likes/dislikes
- Tell time and dates

### Level 3: Intermediate (B1) - "Berategnaw" (One Who Travels)
**Goal:** Handle most travel situations, express opinions

| Metric | Target |
|--------|--------|
| Vocabulary | 1000-1500 words |
| Study Time | ~120 hours |
| XP Range | 1500-3500 |
| Fidel Mastery | 100% |

**Can-Do Statements:**
- Discuss past events
- Make plans and appointments
- Handle unexpected travel situations
- Express opinions and preferences
- Understand main points of familiar topics

### Level 4: Upper Intermediate (B2) - "Astawaki" (One Who Knows)
**Goal:** Comfortable conversations on various topics

| Metric | Target |
|--------|--------|
| Vocabulary | 2000-3000 words |
| Study Time | ~200 hours |
| XP Range | 3500-7000 |

**Can-Do Statements:**
- Discuss abstract topics
- Express nuanced opinions
- Understand news and articles
- Write formal and informal messages
- Handle professional conversations

## Topic Classification (Units)

### Unit 0: Foundations
**Topics:**
1. **Fidel Script (ፊደል)** - Amharic alphabet (33 base characters x 7 forms)
2. **Pronunciation** - Ejective consonants, vowel sounds
3. **Ge'ez Numbers** - Traditional numbering system

### Unit 1: Greetings & Introductions (ሰላምታ)
**Level:** A1 | **Lessons:** 5

| Lesson | Topics | Key Phrases |
|--------|--------|-------------|
| 1.1 | Basic Greetings | ሰላም (selam), ጤና ይስጥልኝ (t'ena yistilign) |
| 1.2 | Time-based Greetings | እንደምን አደርክ/ሽ (good morning), እንደምን ዋልክ/ሽ (good afternoon) |
| 1.3 | Introductions | ስሜ ... ነው (my name is...), ከየት ነህ/ሽ? (where are you from?) |
| 1.4 | Polite Expressions | እባክዎን (please), አመሰግናለሁ (thank you), ይቅርታ (sorry) |
| 1.5 | Farewells | ደህና ሁን/ሁኚ (goodbye), ቻው (ciao) |

### Unit 2: Numbers & Time (ቁጥሮች)
**Level:** A1 | **Lessons:** 5

| 3.2 | Extended Family | አያት (grandparent), አጎት (uncle), አክስት (aunt) |

### Unit 4: Food & Dining (ምግብ)
**Level:** A2 | **Lessons:** 5

| Lesson | Topics | Key Vocabulary |

| 4.2 | Drinks | ቡና (coffee), ቻይ (tea), ውሃ (water), ቢራ (beer), ጠጅ (tej) |

### Unit 5: Travel & Directions (ጉዞ)
**Level:** A2 | **Lessons:** 5

| Lesson | Topics | Key Phrases |
|--------|--------|-------------|
| 5.1 | Transportation | አውቶቡስ (bus), ታክሲ (taxi), አውሮፕላን (airplane) |
| 5.2 | Directions | ወደ ቀኝ (to the right), ወደ ግራ (to the left), ቀጥታ (straight) |

## Gamification Elements

### XP System
| Action | XP Earned |
|--------|-----------|
| Complete Lesson | +25 XP |
| Perfect Quiz (100%) | +50 XP |
| Daily Streak | +10 XP |
| Level Up | +100 XP |
| Master a Unit | +200 XP |

### Achievements
- **First Steps**: Complete first lesson
- **Polyglot Beginner**: Reach Level 2 (A2)
- **Conversation Ready**: Complete all dialogue scenarios
- **Fidel Master**: Learn all 238 Fidel characters
- **Streak Champion**: 30-day streak
- **Cultural Explorer**: Complete Culture unit

### Streaks & Motivation
- Daily goal: 10-50 XP (user-configurable)
- Streak freeze: Save streak for 1 missed day
- Weekly challenges: Bonus XP for completing extra content
- Leaderboards: Compete with friends

## Implementation Notes

### Data Model Updates Needed:
```swift
struct Level: Identifiable, Codable {
    let id: Int
    let name: String           // "Selam", "Wendim", etc.
    let cefrLevel: String      // "A1", "A2", etc.
    let requiredXP: Int
    let badge: String          // SF Symbol name
    let color: String          // Hex color
}

struct Unit: Identifiable, Codable {
    let id: Int
    let title: String
    let titleAmharic: String
    let level: Int             // Required level to unlock
    let lessons: [Lesson]
    let icon: String
}

struct Lesson: Identifiable, Codable {
    let id: String
    let unitId: Int
    let title: String
    let type: LessonType       // .vocabulary, .grammar, .conversation, .culture
    let content: [LessonContent]
    let xpReward: Int
}
```

### Progressive Unlocking:
1. Units unlock based on user level
2. Lessons unlock sequentially within units
3. "Checkpoint" quizzes every 5 lessons
4. Unit tests to mark unit completion
