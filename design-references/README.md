## Usage

These references serve as:
- **Inspiration** for future design iterations
- **Color palette** exploration beyond Fidel's Ethiopian scheme
- **Typography** and layout pattern studies
- **Contrast examples** for accessibility testing

## Adding New References

When documenting a new design system:

1. Create a dedicated `.md` file (e.g., `site-name-analysis.md`)
2. Include:
   - Color palette with hex values
   - Typography specifications
   - Layout patterns
   - Design principles
   - Screenshots/visual references
3. Update this README with a summary
4. Store related assets (screenshots, color swatches) in this directory
